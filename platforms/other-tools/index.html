How it connects

APIs, MCP, and webhooks. That's all we need.

The integration approach

If a tool has an API, an MCP server, or webhook support, we can build agents around it. That covers the vast majority of the business software in use today. We don't need vendor partnerships or marketplace listings to connect. We build directly against the interfaces your tools already expose.

Every integration is scoped, authenticated through your org's credentials, and governed under the same access control and audit trail as the rest of your colony. No shadow connections, no personal API keys, no access that outlives the person who set it up.
